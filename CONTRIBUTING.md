# Contribuer à Nautilus

Merci de votre intérêt pour le projet.

## Licence

Le code est publié sous licence [PolyForm Noncommercial 1.0.0](LICENSE) : réutilisation,
modification et redistribution libres, sauf usage commercial.

## Accord de contribution (CLA)

Avant qu'une contribution soit acceptée, son auteur accepte l'accord de contribution décrit dans
[nautilus/docs/CLA.md](https://github.com/hayupisama/nautilus/blob/main/docs/CLA.md). Il permet au
titulaire des droits de conserver la possibilité de faire évoluer la licence du projet.

## Conventions

- Messages de commit : [Conventional Commits](https://www.conventionalcommits.org/fr/) (`feat:`, `fix:`, `docs:`, `chore:`…).
- Une branche par sujet, fusion par pull request.
- Toute interface doit respecter les exigences d'accessibilité (WCAG 2.2 AA) du cahier des charges.
