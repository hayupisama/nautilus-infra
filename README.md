# nautilus-infra

Infrastructure du projet Nautilus (nom de code) : un VPS en France, k3s, charts Helm, secrets chiffrés,
sauvegardes et supervision.

## Environnement local

PostgreSQL/PostGIS et Keycloak (realm `nautilus` préconfiguré, comptes de test) en une commande :
voir [local/README.md](local/README.md).
